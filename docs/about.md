# 关于本站

## 为什么做这件事

《生成式软件工程》是一门全部开放的课程：B 站直播、课件开源、实验在线可跑。但视频形态不利于检索、引用和复习——你没法"全文搜索一节课"。本站在原视频之外提供一个**可搜索、可跳转、可引用**的图文版本。

这也是课程理念的实践：蒋老师在课上谈到，大模型可以把课程切片、开源、让全世界的人参与维护——传统的授课方式会被颠覆。本站正是这条流水线的一个实例。

## 生产管线

每一讲的诞生过程：

1. **ASR 初转**：本地小模型 / 夸克转写，得到逐字稿
2. **整理校对**：Agent 辅助划分时间块、保留课堂原始表达（口误、中英文混杂原样保留）
3. **合成 PDF**：图文并排、带时间戳的转录 PDF
4. **自动拆解**：脚本将 PDF 拆成 Markdown + 截图，发布到本站（`scripts/pdf_to_md.py`）

整条管线除人工抽检外全自动，每周讲次更新约需几分钟。

## 纠错与贡献

- 发现转录错误？欢迎到 [GitHub Issues](https://github.com/aurora1112-j/nju-generative-se/issues) 指出，格式：`讲次 + 时间戳 + 应为`
- 更推荐直接对照 [B 站原视频](#) 确认——所有正文时间戳均可对照跳转
